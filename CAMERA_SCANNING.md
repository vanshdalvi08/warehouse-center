# Camera barcode scanning

Barcode and location fields have a Scan button in Inbound, Inventory transfers, Outbound picking/packing/dispatch and the guided Workflow. The product registration barcode field also supports scanning an existing supplier label.

1. Click Scan beside the field you want to fill.
2. Allow camera access when the browser requests it. The scanner prefers a rear camera on devices that have one and requests video only.
3. Hold the entire printed barcode in view, with good lighting and steady focus. The app supports Code 128 labels generated by the project, plus Code 39, EAN-13, EAN-8, UPC-A, UPC-E, ITF and QR codes.
4. A successful scan stops the camera and fills that field. Review it and click the existing confirmation button. Scanning alone never submits an operation or changes inventory.
5. Close the scanner or press Escape to return to manual input. The camera is released on close, capture and unmount, including when camera permission resolves after the dialog was closed.

For location dropdowns, only a currently listed option is accepted. Unknown/blocked/wrong-type location scans leave the selection unchanged and show guidance. Input fields retain the existing server-side product, source, quantity and carton validation.

Camera frames are decoded locally by the lazily loaded ZXing browser library and are not uploaded. Access needs browser permission and a secure context (HTTPS or localhost/loopback on the same device). A phone opening an ordinary HTTP LAN address will not have the same secure-context exemption as localhost. Denied, missing, busy and unsupported cameras show a message with manual entry available.

Useful references: [ZXing browser API](https://github.com/zxing-js/browser), [browser camera requirements](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia).

Verification: component tests simulate camera permissions, detection, controlled/uncontrolled fields, valid/invalid location options, late permission resolution and cleanup. Separate tests decode real synthetic Code 128 barcode images for product, location and carton values. Physical camera performance, focus and lighting still require testing on the presentation device.
